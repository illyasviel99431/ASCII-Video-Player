# 개인 제작 프로젝트 ASCII-Video-Player
ASCII 영상 재생 웹사이트

## 제작기간
# 2026. 09. 28 ~ 2026. 09. 30

## 프로젝트 소개
HTML, CSS, JavaScript를 활용하여 동영상을 ASCII 문자로 변환하고 실시간으로 재생하는 웹사이트를 제작한 개인 프로젝트 입니다.
JavaScript의 Canvas API를 이용해 영상의 각 프레임에서 픽셀 데이터를 추출하고, 픽셀의 밝기에 따라 서로 다른 ASCII 문자로 변환하여 화면에 출력하도록 구현했습니다. 또한 원본 픽셀의 RGB 색상값을 적용하여 ASCII 문자로도 영상의 생상을 표현할 수 있도록 제작했습니다.
사용자가 직접 영상 파일을 선택할 수 있으며, 해상도 조절, 재생 및 일시정지 기능을 구현했습니다. 화면크기에 따라 ASCII 출력 영역이 자동으로 조정되도록 구성했습니다.

## 사용 기술
HTML, CSS, JavaScript, Canvas API
